Maxim Culbeaux personal website

Plain HTML, CSS, and JavaScript. No dependencies, server, database, or build step.

Open index.html directly or serve the repository root with any static web server.

Vercel
Import this GitHub repository. Select the static framework option, which may be labeled Other. Leave the build command empty. Set the output directory to the repository root, a single period. Leave the root directory at the repository root.

Netlify
Import the same GitHub repository. Leave the build command empty. Set the publish directory to the repository root, a single period. Leave the base directory at the repository root.

All internal links and assets use relative paths. External project, email, and LinkedIn links use their supplied destinations. There are no host specific configuration files. The same files can be served on either host or a custom domain without changes.

Photos supplied by Maxim Culbeaux, resized and compressed for the web. Only the four requested photos are used. The suit photo already has a softly blurred setting.
